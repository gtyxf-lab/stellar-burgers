# Stellar Burgers

Веб-приложение космической бургерной: собираешь бургер из ингредиентов, оформляешь заказ и следишь за лентой заказов в реальном времени.

Учебный проект [Яндекс Практикума](https://practicum.yandex.ru/) — финальная работа по React и Redux.

## Что умеет приложение

- **Конструктор** — выбор булки и начинки, подсчёт стоимости
- **Лента заказов** — общая лента и статусы заказов
- **Авторизация** — регистрация, вход, восстановление пароля
- **Личный кабинет** — данные профиля и история заказов
- **Защищённые маршруты** — доступ к профилю только после входа
- **Модальные окна** — детали ингредиента и заказа поверх текущей страницы

## Стек

React · TypeScript · Redux Toolkit · React Router · Webpack

Тесты: Jest · Cypress

## Запуск

1. Установи зависимости:

```bash
npm install
```

2. Создай файл `.env` по образцу `.env.example`:

```env
BURGER_API_URL=https://norma.education-services.ru/api
```

3. Запусти dev-сервер:

```bash
npm start
```

Приложение откроется на `http://localhost:4000`.
